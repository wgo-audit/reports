# Architecture: Runtime, Deployment, Delivery, Identity, and Secrets

## Boundary

- Pinned source: `docusealco/docuseal` release `3.1.7`, commit `a2d8b855491793870b7b4acf176d2d95ae95ff83`; locally verified by `git rev-parse HEAD` and `git describe --tags --exact-match HEAD`.
- This packet describes configured source topology and approved public documentation. It does not establish a live deployment, control effectiveness, production approval, secret values, ownership, or Pro implementation behavior.
- Status meanings: **observed** = directly present in pinned source; **documented** = public-site intent not bound to this release; **inferred** = source-supported architectural implication requiring validation; **unknown** = evidence not supplied.
