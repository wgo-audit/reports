No file under `spec/` changed. The commit range includes mobile navigation/modal/filter work and changes to the signer form, template builder, payment step, and completion job. For the organization's web/mobile onboarding decision, targeted mobile viewport, supported browser/webview, accessibility, payment/phone, signer completion, back-navigation, and modal/filter regression evidence remains unresolved.
